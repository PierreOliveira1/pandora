# Documentation

Pandora is one local CLI that connects many services and many accounts of the same service to every AI client. Start with the getting started guide, then read the page for the topic you need.

- [Getting started](getting-started.md): install Pandora, add a first account, connect an AI client and run a tool.
- [Concepts](concepts.md): services, accounts, account refs, source kinds, the catalog cache, skill versus MCP, and the daemon.
- [Sources](sources.md): add remote MCP servers, local MCP servers, OpenAPI specs and command tools.
- [Accounts and login](accounts-and-login.md): OAuth, static headers, secret storage, default accounts, rename and remove.
- [AI clients](ai-clients.md): install the skill or the MCP server in each client, keep the skill in sync, and uninstall.
- [Safety](safety.md): read-only, allow and deny rules, the call log and client detection.
- [Web UI](web-ui.md): open the local UI, what each screen does, and its security model.
- [Configuration](configuration.md): file locations, `config.toml`, and environment variables.
- [CLI reference](cli.md): every command, flag and an example.
- [Architecture](architecture.md): package map, request flow, state and testing for contributors.

Project files: [README](../README.md), [CONTRIBUTING](../CONTRIBUTING.md), [SECURITY](../SECURITY.md), [AGENTS](../AGENTS.md).
